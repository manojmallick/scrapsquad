# ScrapSquad.io

ScrapSquad.io is a browser arena game prototype. Play a round against AI opponents, collect loot, and compete for the highest score.

## Run

```bash
pnpm install
pnpm dev
```

Use WASD or arrow keys to move; click to attack.

## Build

```bash
pnpm build
pnpm typecheck
```

Game logic is organized under `src/logic/`. The project currently runs locally with AI opponents.
